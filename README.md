# 🏦 Dart Banking System

A **console-based Banking Management System** built using **Pure Dart**. This project demonstrates Object-Oriented Programming (OOP), file handling, data management, and clean software architecture while simulating real-world banking operations.

---

## 📖 Project Overview

The Dart Banking System allows users to create bank accounts, securely log in, perform banking transactions, and view account information through a command-line interface.

This project is designed to strengthen core Dart programming skills without using Flutter.

---

## ✨ Features

### 👤 User Management
- Create a new bank account
- Auto-generate account numbers
- Login system
- Update user profile

### 💳 Account Management
- View account details

### 💰 Banking Operations
- Deposit money
- Withdraw money
- Transfer money between accounts
- Balance validation
- Transaction recording

### 📜 Transaction History
- View all transactions

### 👨‍💼 Admin Panel
- View all customers
- Search customer accounts
- Block accounts
- Delete accounts



## 🛠️ Technologies Used

- Dart
- Object-Oriented Programming (OOP)
- Collections (List, Map)
- Exception Handling
- File Handling
- Async Programming

## 🚀 Getting Started

### Prerequisites

- Dart SDK 3.x or later

Verify your installation:

```bash
dart --version
```

---

### Clone the Repository

```bash
git clone https://github.com/joelharish/BankSystem.git
```

Navigate into the project directory:

```bash
cd BankSystem
```

Install dependencies:

```bash
dart pub get
```

Run the application:

```bash
dart run
```
